T1: TOTP Hợp Lệ IDLE

Login password → nhập OTP đúng lần đầu → HTTP 200, MFA verified.

T2: Replay OTP IDLE

Gửi lại đúng OTP của T1 trong cùng time-step → HTTP 401 REPLAY_DETECTED.

T3: OTP Sai / Hết Hạn IDLE

Gửi OTP sai hoặc ngoài cửa sổ cho phép → 401, không cấp session đặc quyền.

T4: Session Fixation IDLE

So sánh SID trước và sau MFA: SID_before != SID_after, SID cũ bị hủy (401).

T5: RBAC Bypass IDLE

Dùng phiên CSKH gọi trực tiếp API approve → 403 Forbidden, audit DENIED.

T6: Luồng Hợp Lệ SoD IDLE

CSKH tạo refund request; Kế toán approve → Thành công đúng role (201/200).

T7: Log Masking IDLE

Gửi thẻ có PAN & CVV → Không có CVV trong log, PAN chỉ còn ************last4.

T8: Session Revocation IDLE

Logout/Revoke all → Gọi API bằng session cũ trả về 401 Unauthorized.
