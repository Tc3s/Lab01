06 Kiểm Soát An Ninh Cốt Lõi

Đáp ứng 100% tiêu chuẩn kỹ thuật
1

TOTP RFC 6238

PASS T1 / T3

6 chữ số, time-step 30s, clock drift ±1 step. Thuật toán HMAC-SHA1 client-side hoàn toàn độc lập khớp chuẩn pyotp.

OTP Hiện Tại (cskh_user): ------
Hết hạn sau: --s
2

Redis Anti-Replay

PASS T2

Lệnh atomic SET otp_replay:{uid}:{step} "consumed" EX 90 NX. Chặn hoàn toàn replay OTP trong cùng time-step window (HTTP 401).

3

Session Hardening

PASS T4

Cookie HttpOnly, SameSite=Lax. Xoay Session ID ngay khi xong MFA (SID_before ≠ SID_after); pre-MFA token bị hủy lập tức trong Redis.

Idle Timeout: 15 phút rolling
Absolute Timeout: 8 giờ hard-limit
4

RBAC & SoD

PASS T5 / T6

Phân tách nhiệm vụ độc lập: CSKH tạo yêu cầu (201 Created), Kế toán duyệt chi (200 OK). CSKH approve bị chặn 403 Forbidden.

Four-Eyes: CSKH ≠ KETOAN ≠ ADMIN
5

PCI-DSS Data Masking

PASS T7

Số thẻ PAN chỉ lưu và log last-4 (************last4). Mã CVV/CVC bị loại bỏ tức thì tại schema, tuyệt đối không vào DB hoặc log.

PAN Lưu DB: ************4444
Mã CVV: [REDACTED / TRASHED]
6

Session Revocation

PASS T8

Hủy session ngay khi logout hoặc đổi mật khẩu. Cung cấp API revoke-all xóa toàn bộ session của user trên Redis Set index.
