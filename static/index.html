Bộ Test Tự Động & Chứng Minh 6 Control Bảo Mật

Khởi chạy toàn bộ 8 bài test bắt buộc (T1 → T8) để chứng minh kiểm soát hoạt động chuẩn xác theo tài liệu đề bài.

1

TOTP RFC 6238

PASS T1/T3

6 chữ số, chu kỳ 30s, cho phép clock drift ±1 step (90s window). Secret lưu chuẩn Base32 shielded.

Mã TOTP Hiện Tại: ------
Thời gian còn lại: --s
2

Redis Anti-Replay

PASS T2

Lệnh atomic SET otp_replay:{uid}:{step} "consumed" EX 90 NX. Gửi lại OTP trong cùng step bị từ chối 401 ngay lập tức.

3

Session Hardening

PASS T4

Xoay vòng Session ID ngay sau khi xác thực MFA (SID_before ≠ SID_after). Hủy session cũ trên Redis; Cookie HttpOnly, SameSite=Lax.

Idle Timeout: 15 phút rolling
Absolute: 8 giờ hard-limit
4

RBAC & SoD

PASS T5/T6

Kiểm tra ủy quyền ở tầng backend API. CSKH gọi approve nhận 403 Forbidden + log DENIED. Kế toán được duyệt chi.

Separation: CSKH ≠ KETOAN ≠ ADMIN
5

Data Masking

PASS T7

PAN mask còn ************last4. CVV bị tiêu hủy lập tức tại tầng schema, tuyệt đối không vào database hoặc log.

PAN Lưu: ************4444
CVV: [REDACTED / TRASHED]
6

Revocation

PASS T8

Hủy phiên khi logout, đổi mật khẩu hoặc reset MFA. Tính năng thu hồi toàn bộ phiên (Revoke All) qua Redis Set index.
